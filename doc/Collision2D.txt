# Metodologia

Assim como na entrega anterior, inicialmente fiz a implementação manualmente e então fiz com que uma IA revisasse meu código.

A IA fez a seguinte observação:
- `Collision2D.cpp`: `AABB::intersects` (strict `<` -> touching edges count as
  overlap, per doc), `Collision2D::bounds` (`position ± halfExtents`).

# Implementação

`Collision2D.cpp` define as funções de membro declaradas e não
definidas em `Collision2D.hpp`. É detecção narrow-phase apenas: dados
dois boxes, verifica se há sobreposição.

# AABB

## AABB::intersects

Testa a sobreposição de dois boxes alinhados aos eixos com o teste de
separação por eixos. Dois boxes são disjuntos apenas se um estiver
inteiramente à esquerda, à direita, acima ou abaixo do outro:

    return !(max.x < other.min.x || other.max.x < min.x
            || max.y < other.min.y || other.max.y < min.y);

Como as comparações usam `<` estrito, bordas que se tocam (ex.:
`max.x == other.min.x`) não são consideradas disjuntas — ou seja,
tocar nas bordas conta como sobreposição, conforme o contrato no
header.

# Collision2D

## Collision2D::bounds

Constrói o AABB em espaço do mundo, centrado em `position`, a partir
dos meios-extensões (halfExtents):

    { position - halfExtents, position + halfExtents }

O shape padrão é um quadrado de lado `TILE_SIZE` (64 x 64 pixels),
armazenado como `halfExtents = { TILE_SIZE * 0.5f, TILE_SIZE * 0.5f }`.
