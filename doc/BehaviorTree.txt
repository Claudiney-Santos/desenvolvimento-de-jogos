# Implementação

`BehaviorTree.cpp` define as funções de membro declaradas e não
definidas em `BehaviorTree.hpp`: os construtores dos nós
(`SelectorNode`, `SequenceNode`, `ConditionNode`, `ActionNode`) e de
`BehaviorTree`, além do método `tick` de cada nó e da própria árvore.

Sendo estas funções:

- SelectorNode::SelectorNode
- SelectorNode::tick
- SequenceNode::SequenceNode
- SequenceNode::tick
- ConditionNode::ConditionNode
- ConditionNode::tick
- ActionNode::ActionNode
- ActionNode::tick
- BehaviorTree::BehaviorTree
- BehaviorTree::tick

# Nós compostos

## SelectorNode::SelectorNode

Construtor que move a lista de filhos recebida para o membro
`m_children`, armazenando-a como `std::vector<BTNodePtr>`.

## SelectorNode::tick

Percorre os filhos da esquerda para a direita e retorna o resultado
do primeiro filho que reportar `success == true`, propagando também o
comando carregado por ele. Se todos os filhos falharem, retorna
`{ false, "" }` — ou seja, o seletor falha sem comando.

## SequenceNode::SequenceNode

Construtor análogo ao de `SelectorNode`: move a lista de filhos para
`m_children`.

## SequenceNode::tick

Executa os filhos em ordem, da esquerda para a direita. Ao primeiro
filho que falhar, retorna imediatamente `{ false, "" }` (fail-fast).
Caso todos os filhos sucedam, retorna `{ true, lastCommand }`, onde
`lastCommand` é o último comando não vazio produzido pelos filhos —
condições bem-sucedidas não carregam comando e, portanto, não
sobrescrevem o último comando útil.

# Nós folha

## ConditionNode::ConditionNode

Construtor que armazena o nome do fato a ser consultado em `m_name`.

## ConditionNode::tick

Procura `m_name` no contexto (uma lista de pares `{ string, int }`).
Se o nome for encontrado com valor não nulo, retorna `{ true, "" }`
(sucesso, sem comando); se não for encontrado ou tiver valor zero,
retorna `{ false, "" }`.

## ActionNode::ActionNode

Construtor que armazena a string de comando em `m_command`.

## ActionNode::tick

Sempre retorna `{ true, m_command }`. O parâmetro `context` é
ignorado (marcado com `(void)`), pois uma ação não inspeciona o
contexto.

# BehaviorTree

## BehaviorTree::BehaviorTree

Construtor que move o nó raiz recebido para `m_root`.

## BehaviorTree::tick

Avalia a árvore uma única vez contra `context`. Se `m_root` for nulo,
retorna `""` (nenhum comando). Caso contrário, chama `m_root->tick`
e retorna o comando do resultado quando `success` é verdadeiro, ou
`""` quando a raiz falha.
